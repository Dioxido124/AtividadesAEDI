# Atividades de AEDI - Algoritmos e Estruturas de Dados I

Este repositório reúne as atividades práticas desenvolvidas durante a disciplina de AEDI, organizadas por etapas e conteúdos programáticos. O objetivo é registrar o progresso no aprendizado de lógica de programação e estruturas de dados utilizando a linguagem Java.

## Estrutura do Repositório

Os arquivos seguem o padrão de nomenclatura acadêmico: `CXXEXYY`, onde:
* **CXX:** Representa o Conteúdo (ex: C01, C09, C11).
* **EXYY:** Representa o número do Exercício.

---

## Etapa 1: Fundamentos e Entrada de Dados
Foco inicial em aprender como o computador recebe e exibe informações.

* **Conteúdos Iniciais:** Técnicas de entrada de dados (`Scanner`), manipulação de variáveis e diferentes formas de saída formatada no console (`printf`, `println`).
* **Objetivo:** Compreender a estrutura básica de um programa Java e a interação inicial com o usuário.

## Etapa 2: Estruturas de Controle e Lógica Avançada
Aprofundamento na lógica para resolução de problemas complexos.

* **Estruturas Condicionais:** Uso de `if`, `else` e `switch` para tomada de decisão (ex: classificação de cargos e salários).
* **Estruturas de Repetição:** Aplicação de `for`, `while` e `do-while` para processamento de múltiplos dados.
* **Séries Matemáticas (C09):** Exercícios focados em cálculos sequenciais e fórmulas matemáticas complexas.
* **Manipulação de Arquivos:** Leitura de dados externos e tratamento de buffers.

## Etapa 3: Modularização, Listas e Orientação a Objetos Básica
Introdução a conceitos fundamentais para a criação de sistemas mais robustos, dinâmicos e organizados.

* **Funções (Métodos):** Modularização do código através da criação de rotinas reutilizáveis, compreensão da passagem de parâmetros e tipos de retorno.
* **Listas e Estruturas de Dados:** Manipulação de coleções de dados. Transição de vetores clássicos (arrays) para coleções dinâmicas do Java (como `ArrayList`), e estudo prático de estruturas dinâmicas da computação, como listas encadeadas.
* **Orientação a Objetos (Básico):** Introdução ao paradigma orientado a objetos. Modelagem e criação de classes, definição de atributos, métodos e instanciação de objetos.

---

## Tecnologias e Ferramentas

* **Linguagem:** Java (JDK 11 ou superior)
* **Ambiente de Desenvolvimento:** IntelliJ IDEA
* **Conceitos Acadêmicos:** Algoritmos lineares, progressões, controle de fluxo, modularização, estruturas de dados dinâmicas e paradigma orientado a objetos.

## Como Explorar

Cada pasta de "Etapa" contém os códigos-fonte organizados. Você pode encontrar exemplos que vão desde um simples "Olá Mundo", passando por cálculos matemáticos e manipulação de arquivos, até a implementação de coleções e classes em Java.
