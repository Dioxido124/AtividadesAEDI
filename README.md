Atividades de AEDI - Algoritmos e Estruturas de Dados I
Este repositório reúne as atividades práticas desenvolvidas durante a disciplina de AEDI, organizadas por etapas e conteúdos programáticos. O objetivo é registrar o progresso no aprendizado de lógica de programação utilizando a linguagem Java.

Estrutura do Repositório
Os arquivos seguem o padrão de nomenclatura acadêmico: CXXEXYY, onde:

CXX: Representa o Conteúdo (ex: C01, C09).

EXYY: Representa o número do Exercício.

 Etapa 1: Fundamentos e Entrada de Dados
Foco inicial em aprender como o computador recebe e exibe informações.

Conteúdos Iniciais: Técnicas de entrada de dados (Scanner), manipulação de variáveis e diferentes formas de saída no console (printf, println).

Objetivo: Compreender a estrutura básica de um programa Java e a interação com o usuário.

Etapa 2: Estruturas de Controle e Lógica Avançada
Aprofundamento na lógica para resolução de problemas complexos.

Estruturas Condicionais: Uso de if, else e switch para tomada de decisão (ex: classificação de cargos e salários).

Estruturas de Repetição: Aplicação de for, while e do-while para processamento de múltiplos dados.

C09 - Séries Matemáticas: Exercícios focados em cálculos sequenciais e fórmulas matemáticas complexas.

Manipulação de Arquivos: Leitura de dados externos e tratamento de buffers.

 Tecnologias e Ferramentas
Linguagem: Java (JDK 11 ou superior).

Ambiente de Desenvolvimento: IntelliJ IDEA.

Conceitos Acadêmicos: Algoritmos lineares, progressões, controle de fluxo e modularização.

Como Explorar
Cada pasta de "Etapa" contém os códigos-fonte organizados. Você pode encontrar exemplos que vão desde um simples "Olá Mundo" até simulações de crescimento exponencial e cálculos de geometria analítica.
